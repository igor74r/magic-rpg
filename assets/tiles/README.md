# 2D Tile Assets

Оригинальные SVG-атласы, созданные для «Осколков Кристалла Маны». Не требуют CDN, внешних запросов или сторонних библиотек.

- `terrain/atlas.svg`: тайлы 48×48; пять столбцов соответствуют типам карты `0…4`, восемь строк — биомам.
- `dungeons/atlas.svg`: декоративный набор полов, стен, дверей, трещин и магических печатей.
- `props/atlas.svg`: сундуки, кристаллы, алтари, фонари, мосты, порталы, кости и грибы.
- `manifest.json`: размеры и индексы биомов.

`ui/overworld/tile-atlas.js` загружает terrain atlas лениво. Пока SVG не загружен, текущий Canvas-рендер продолжает рисовать процедурные тайлы; при ошибке загрузки действует тот же fallback.
