# 2D Pixel-Art Tile Assets

Все активные тайлы мира загружаются из локальных PNG-атласов и отображаются через Canvas 2D с отключённым сглаживанием.

- `terrain/atlas.png`: 5 столбцов × 8 биомов; исходные тайлы 96×96, отображаются как 48×48.
- `props/atlas.png`: 8×4 тематических набора; исходные спрайты 96×96, отображаются как 48×48.
- `dungeons/atlas.png`: декоративный набор тайлов пола, стен, дверей, трещин и магических печатей (48×48).
- `manifest.json`: размеры, порядок столбцов и индексы биомов.

SVG для тайлов деревни не использовать. Архитектура Авроры рисуется жёсткими пиксельными блоками в Canvas 2D; сглаживание отключено. Новые тайлы, декорации и здания не добавлять в SVG. Все игровые изображения остаются локальными, без CDN и внешних запросов.
