## Подтверждённые дефекты, исправления и регрессии

### 1. Проверка синтаксиса неполного набора JS
**Дефект:** workflow проверял только `.js`, но в проекте 74 исполняемых/проверочных файла `.mjs` (включая тесты и скрипты). Их синтаксические ошибки не ловились на CI.
**Исправление:** `.github/workflows/ci.yml` теперь запускает `node --check` для всех `.js` и `.mjs`, исключая `.git` и `node_modules`.
**Проверка:** CI на HEAD прошёл, step `Syntax check all JavaScript modules and scripts` — success.

### 2. New Game+ выставляла XP-порог, отличный от основной системы
**Дефект:** `systems/ngplus.js` сбрасывал героя на `level: 1, expNext: 100`, тогда как общий `getExpNext(1)` задаёт 125. HUD показывал неправильный порог; логика прогрессии затем исправляла значение лишь при следующем вызове `addExp`.
**Исправление:** New Game+ использует `getExpNext(1)` из `systems/progression.js`.
**Регрессия:** `scripts/check-ngplus.mjs` проверяет совпадение порога с общей кривой.
**Проверка:** CI — success.

### 3. New Game+ не откатывал переход при ошибке сохранения
**Дефект:** функция сбрасывала сюжет, уровень, флаги, локацию и состояние цикла, затем игнорировала `saveGame()`. При quota/storage/serialization error могла сообщить об успешном NG+, хотя новое состояние не было сохранено.
**Исправление:** `systems/ngplus.js` сохраняет snapshot затрагиваемых данных; при `saveGame() === false` восстанавливает игрока и сюжетные поля, показывает сообщение и возвращает `false`. События успешного NG+ не отправляются.
**Регрессия:** `scripts/check-ngplus.mjs` симулирует ошибку записи и проверяет возврат исходного уровня, номера цикла, флагов кампании и локации.
**Проверка:** CI — success. Один промежуточный прогон теста завершился ошибкой из-за неверного тестового ожидания локации; fixture исправлен, повторный CI прошёл. Не скрывать этот промежуточный fail.
