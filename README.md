# Осколки Кристалла Маны

[![CI](https://github.com/igor74r/magic-rpg/actions/workflows/ci.yml/badge.svg)](https://github.com/igor74r/magic-rpg/actions/workflows/ci.yml)
[🎮 Играть](https://igor74r.github.io/magic-rpg/)

Браузерная 2D-RPG с видом сверху в жанре тёмного фэнтези. Три игровых класса, пошаговые бои на карте, расширенная система экипировки, сюжетная кампания из пяти актов и локальный эндгейм.
Проект работает как статический сайт на JavaScript ES-модулях: без backend, серверной БД, сборки и сетевых игровых функций.

## Глобальное издание v0.19

- **Классы:** Воин, Маг и Лучник с отдельными боевыми параметрами, способностями и стилями игры. В бою учитываются уклонение, блок, сила блока, критический шанс, пробитие брони и эффекты состояний.
- **Пассивные деревья:** по 5 ветвей и 31 узлу на класс (30 пассивных узлов и стартовый), всего 93 узла для трёх классов, с требованиями уровней и связями между узлами.
- **Сюжет:** 5 актов по 5 миссий. Все 25 миссий распределены по 15 приключенческим регионам; задание нужно принять, выполнить в нужной области и сдать.
- **Мир:** 16 локаций — деревня Аврора и 15 приключенческих регионов. В данных 43 типа врагов, включая пять новых сюжетных вариантов и отдельных боссов актов.
- **Инвентарь:** 12 слотов — оружие, голова, плечи, грудь, спина, запястья, кисти, ноги, два кольца, амулет и печать. Всего 68 предметов, включая руны, гнёзда, материалы и свитки.
- **Магия:** 14 заклинаний, изучаемых классом или свитками.
- **Хроники:** четыре главы истории, три фракции и пять нитей побочных сюжетов.
- **2D-ресурсы:** локальные SVG-атласы поверхности, объектов и подземелий; атлас объектов используется для сундуков и событий с биомными палитрами, для недоступного атласа предусмотрен процедурный fallback; добавлена эмблема Кристалла Маны.
- **Сохранения:** схема v13 с миграциями старых персонажей, анатомическими слотами и прогрессом кампании.

## Запуск

Из корня проекта выполните:

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000 в браузере. Запуск через `file://` не подходит из-за ES-модулей.

## Проверки

```bash
node --check <file.js>
node scripts/check-imports.mjs
node scripts/check-gameapi.mjs
node scripts/smoke-load.mjs
node scripts/smoke-boot.mjs
node scripts/check-economy.mjs
node scripts/check-rarity.mjs
node scripts/check-passives.mjs
node scripts/check-inventory-affixes.mjs
node scripts/check-story-depth.mjs
node scripts/check-visual-assets.mjs
node scripts/browser-smoke.mjs  # requires Playwright + Chromium + Python 3
```

Скрипты проверяют синтаксис, импорты, контракт `GameAPI`, экономику, редкость предметов, деревья талантов, инвентарь, крафт, кампанию и локальные визуальные ресурсы. `browser-smoke.mjs` запускает Chromium и проверяет загрузку игры, вкладки настроек, сохранение параметров и отсутствие горизонтального переполнения на 1440×900, 390×844 и 320×740. Smoke-boot с DOM/Canvas-заглушками остаётся дополнительной проверкой логики.

## Неизменённые части

Пролог, его HTML-сценарий, MP3 и логика озвучки сохранены без изменений. Сетевые игровые функции не добавлялись.
